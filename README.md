# Análise_Exploratória_Dados
Aqui você irá encontrar a atividade do módulo 15 do curso de Cientista de Dados da Ebac.

A atividade consiste em realizar uma análise exploratória de dados, aplicando técnicas estatísticas e visuais para compreender o comportamento das variáveis e identificar padrões relevantes na base de dados.

Durante a atividade serão abordados temas como:

* Análise univariada
* Identificação de outliers
* Construção e interpretação de boxplots
* Análise bivariada
* Extração de insights a partir dos dados

O objetivo é desenvolver uma compreensão mais aprofundada da base analisada, identificando relações entre variáveis, possíveis anomalias e informações relevantes para apoiar tomadas de decisão e futuras modelagens de dados.
